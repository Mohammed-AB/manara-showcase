# Manara Learning: guided demonstration

A selected-content showcase with three authored bilingual reading notes, a reflection hall and recorded live grounded answers.

## A focused walkthrough

1. **Choose a reading.**
2. **switch language.**
3. **explore the hall.**
4. **ask.**
5. **open the source.**

Pause on the evidence at each decision: english / arabic reading; source-linked answers; limited content and persistent allowances.

## Interactive access

The application is available in Mohammed's local Demo Studio. This repository deliberately does not contain a runnable source distribution. A reviewer can inspect the included materials immediately or request a guided limited-demo session through [the portfolio](https://mohammed-ab.github.io/).

## Boundaries

The showcase contains a small authored selection, not the full book library. Automated accessibility checks do not replace human review.
